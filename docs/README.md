# Documentation boundary

The repository contains only documentation needed to build and verify the
application.

- `source-of-truth/` contains the current agreed delivery scope.
- Product and technical references describe only the active implementation.
- Pitch prototype code and design-system review material live in the internal
  prototype archive and are not production source of truth.
- Private contracts, transcripts, commercial notes, research, internal plans,
  and generated artifacts live outside the repository in the sibling
  `solas_guide-internal/` workspace.

Do not reintroduce private or historical working material into this repository
without a specific reason and an explicit source-of-truth decision.
